## Task 3 – Data Cleaning

### 📌 Objective

The objective of this task is to clean a deliberately messy **Café Sales dataset** and transform it into a clean and analysis-ready dataset while documenting the data-cleaning decisions.

### 🧹 What I Worked On

- Created a data quality report to identify missing and invalid values
- Handled `ERROR` and `UNKNOWN` entries
- Identified and removed duplicate records
- Handled missing values using appropriate imputation techniques
- Standardized inconsistent data
- Corrected data types, including dates and numerical values
- Detected outliers using the **IQR method**
- Evaluated whether detected outliers should be retained or removed
- Created a before-vs-after data quality summary
- Exported the cleaned dataset as a CSV file

### 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

### 📂 Dataset

The project uses a **Dirty Café Sales Dataset** containing transaction-level information such as:

- Transaction ID
- Item
- Quantity
- Price Per Unit
- Total Spent
- Payment Method
- Location
- Transaction Date

## Dataset Source

The dataset was obtained from Kaggle.
