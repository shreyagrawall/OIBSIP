# Task 1 - Retail Sales Data Analysis

This folder contains the Retail Sales Exploratory Data Analysis (EDA) project completed as part of the Oasis Infobyte Data Analytics Internship.

## Dataset Source

The dataset was obtained from Kaggle.

[Customer Segmentation and Sales Data - Kaggle](https://www.kaggle.com/datasets/oscarannim/customer-segmentation)

## Project Description

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python.

The objective is to identify sales patterns, customer behaviour trends, product performance, and actionable business insights from the available retail data.

## Objectives

- Inspect and understand the dataset
- Check data types, missing values, and duplicate records
- Calculate descriptive statistics
- Analyze monthly and quarterly revenue trends
- Analyze customer demographics
- Identify the top 10 best-selling products
- Analyze revenue by product category
- Study correlations between numerical variables
- Identify additional patterns through visualization
- Develop actionable business recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### 1. Data Inspection & Cleaning
- Dataset shape and structure
- Data type inspection
- Missing value analysis
- Duplicate record checking
- Date conversion and preparation

### 2. Descriptive Statistics
- Mean
- Median
- Mode
- Standard deviation
- Numerical variable summary

### 3. Time Series Analysis
- Monthly revenue trends
- Quarterly revenue trends

### 4. Customer Analysis
- Customer age-group distribution
- Gender-wise customer distribution

### 5. Product Analysis
- Top 10 best-selling products
- Revenue by product category

### 6. Correlation Analysis
- Correlation matrix
- Correlation heatmap for numerical variables

### 7. Additional Visualization
- Additional visualization to identify a non-obvious pattern in the retail data

## Key Business Insights

The analysis helps identify:

- Revenue trends across different months and quarters
- Customer demographic patterns
- High-performing products and categories
- Relationships between numerical sales variables
- Areas where the business can improve sales and customer targeting

## Business Recommendations

Based on the analysis, recommendations are provided for:

- Improving product performance
- Focusing on high-performing categories
- Better customer targeting
- Identifying opportunities for increasing revenue
